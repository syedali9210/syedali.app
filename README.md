# syedali.app

My portfolio, with projects and experience. Live at [syedali.app](https://syedali.app).

Built with Next.js, React, and TypeScript, with GSAP and Motion for animation, Lenis for smooth scrolling, and Vercel Analytics and Speed Insights for measurement.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
